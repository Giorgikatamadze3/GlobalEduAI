# პროგრამების დაფარვა და განახლება

მონაცემთა სურათის თარიღი: **2026-10-28**. ძირითადი ფაილებია [`institutions.json`](../Server/data/institutions.json), [`programs.json`](../Server/data/programs.json), [`program-source-registry.json`](../Server/data/program-source-registry.json) და [`program-import-report.json`](../Server/data/program-import-report.json).

საიტი აერთიანებს ფართო მსოფლიო დირექტორიასა და მასზე გაცილებით შეზღუდულ რეალურ პროგრამების კრებულს. **10,268 დაწესებულებაზე პროგრამების სრული მსოფლიო დაფარვა არ არის მიღწეული.** ამ გაფართოების პრიორიტეტია გერმანია და ევროპული დაფინანსების გზები. უნივერსიტეტი, რომელსაც ჩვენთან პროგრამა არ აქვს დაკავშირებული, რეალურ ცხოვრებაში პროგრამების არმქონე უნივერსიტეტად არ ითვლება.

## რა მოიცავს წყარო

[DAAD International Programmes](https://www2.daad.de/deutschland/studienangebote/international-programmes/) აქვეყნებს გერმანული დაწესებულებების საერთაშორისო პროგრამების შერჩეულ ჩამონათვალს. ეს არ არის ყველა გერმანული უნივერსიტეტის ყველა პროგრამის ან მთელი ევროპის რეესტრი. უნივერსიტეტის გერმანული კავშირი ყველა კამპუსის გერმანიაში მდებარეობასაც არ ადასტურებს.

`courseType:4` მხოლოდ სახელში PhD-ს მსგავსების გამო სადოქტორო პროგრამად არ გარდაიქმნება. ენის/მოკლე/მოსამზადებელი კურსები ამ იმპორტის მოდელში არ შედის.

`listingComplete:true` ნიშნავს, რომ კონკრეტული მოთხოვნის ყველა გვერდი წაკითხულია. იგი ეროვნული ან მსოფლიო დაფარვის სისრულეს არ ნიშნავს. ამ სურათში წყაროს `complete:false` რჩება: ოთხ პროგრამაზე ზუსტი ინსტიტუციური საკონტაქტო დომენი ვერ დადასტურდა. დირექტორიასთან შემდეგი დაკავშირების შედეგი ცალკე ინახება იმპორტის ანგარიშში.

**617 საწყისი ჩანაწერი არ დაემატა კატალოგს:** 613-ზე ქვეყნისა და ოფიციალური დომენის ერთმნიშვნელოვანი დამთხვევა ვერ მოიძებნა, ოთხზე — დაწესებულების დომენი ვერ დადასტურდა. მათი მტკიცებულება/მიზეზი ქეშსა და იმპორტის ანგარიშში რჩება. ეს ჩანაწერები არ იცვლება გამოგონილი უნივერსიტეტით ან შემთხვევითი კავშირით.

ბოლო იმავე ქეშის ხელახალი გაშვება იდემპოტენტურია: **0 ახალი, 0 შეცვლილი, 1,657 უკვე არსებული ჩანაწერი**, კვლავ 617 დაუკავშირებელი. ამდენად, ბოლო ანგარიშის `accepted:0` წარმატებული თავდაპირველი იმპორტის გაქრობას არ ნიშნავს.

სხვა ევროპული ქვეყნების უნივერსიტეტების კონკრეტული პროგრამები საწყისი, ინდივიდუალურად გადამოწმებული ჩანაწერებიდანაც რჩება. Finland Studyinfo-ის საჯარო ინტერფეისი გამოკვლეულია, მაგრამ ადაპტერი გამორთულია და მისგან პროგრამების იმპორტი არ არის შესრულებული. ოფიციალური პორტალის არსებობა შესრულებულ იმპორტად არ ითვლება.

[DAAD-ის უფრო ფართო Degree programmes in Germany](https://www.daad.de/en/studying-in-germany/universities/all-degree-programmes/) ცალკე HRK-ის მონაცემებზე დაფუძნებული საძიებო წყაროა. ის ამ International Programmes იმპორტში არ შედის; მისი ფართო სია მიმდინარე კატალოგის რაოდენობად არ უნდა გამოცხადდეს. შემდგომი ინტეგრაცია მოითხოვს ცალკე ადაპტერს, დომენების გადამოწმებასა და წვდომის/ხელახალი გამოყენების პირობების დადასტურებას.

## დაკავშირება და მონაცემების ხარისხი

ახალი ჩანაწერი უნიკალურ დაწესებულებას უნდა დაუკავშირდეს **ქვეყნისა და ოფიციალურად დადასტურებული დომენის** მიხედვით. მხოლოდ მსგავსი სახელი, ქვეყანა ან პროგრამის პოპულარული მიმართულება საკმარისი არ არის. დაუკავშირებელი/ორაზროვანი მონაცემი რჩება ანგარიშში და სხვა უნივერსიტეტზე არ ნაწილდება.

DAAD-ის დეტალურ გვერდზე ზუსტად დაწესებულების სახელით გამოქვეყნებული `c-contact__link` ადგენს უნივერსიტეტის ვებსაიტს. იმავე სახელით ჩამოთვლილი დაწესებულებისთვის მტკიცებულება ქეშდება; ინახება `institutionEvidenceUrl`. ინდივიდუალური პროგრამის გარე ბმული სხვა პროგრამაზე არ გადაიტანება.

დომენის მცირე შესწორებები შესაძლებელია მხოლოდ [`institution-domain-overrides.json`](../Server/data/institution-domain-overrides.json)-ის დათარიღებული ოფიციალური მტკიცებულებით. TalTech-ის შემთხვევაში ძველი `ttu.ee` ოფიციალურად გადადის `taltech.ee`-ზე: ძველი დომენი და სტაბილური ID რჩება, ახალი დომენი ემატება. [`applyInstitutionOverrides`](../scripts/institution-overrides.js) ხელახალ იმპორტზეც გამოიყენება; ეს სახელით ფართო ავტომატურ დაკავშირებას არ ნერგავს.

საწყისი უნივერსიტეტის გვერდით დადასტურებული ველი (`official-source`) და ოფიციალური დირექტორიის ჩანაწერი (`official-directory`) განსხვავებული წარმოშობაა. იმპორტი ინახავს წყაროსა და საწყისი ჩანაწერის ID-ს, URL-ებსა და შემოწმების თარიღს. სხვადასხვა საწყისი ID შეიძლება ერთნაირი სათაურის ტრეკებს ან მიღებებს აღწერდეს; მხოლოდ სათაურით მათი გაერთიანება არ შეიძლება. უფრო მწირი დირექტორიის მონაცემი ხელით გადამოწმებულ ფასს ან მიღების პირობას არ უნდა ანაცვლებდეს.

არ გამოითვლება უცნობი ფასი, GPA, სრული დატვირთვა, მიღების ვადა ან სტიპენდია. რამდენიმე გამოქვეყნებული ენა ინგლისურენოვან დამოუკიდებელ გზად არ გადაიქცევა. დარგის შესაბამისობა მხოლოდ გამოქვეყნებული ზუსტი დისციპლინის კონტროლირებადი სიტყვარით დგინდება; გაურკვეველი და კომპოზიტური საგნები უცნობად რჩება. სრული წესები და უნივერსიტეტის საწყისი გვერდები აღწერილია [პროგრამების წყაროებში](program-sources.md).

## ლიცენზია და ჩამოტვირთვის ფარგლები

Hipo-ის ინსტიტუციური დირექტორია MIT-ლიცენზირებულია; ეს ლიცენზია DAAD-ის პროგრამების მონაცემებს არ გადაეცემა. [DAAD-ის imprint](https://www.daad.de/en/imprint/) აცხადებს საავტორო უფლებებს. ღია მონაცემთა ლიცენზია და შეუზღუდავი bulk-გავრცელების ნებართვა დადასტურებული არ არის. ტექნიკური ხელმისაწვდომობა ასეთ ნებართვას არ ნიშნავს.

ადაპტერი ინახავს მოკლე ფაქტობრივ ველებსა და ატრიბუციას; ფოტოები და სრული აღწერითი ტექსტები არ იმპორტირდება. 2026-10-28-ს DAAD-ის შესაბამისი ჰოსტის `robots.txt` აბრუნებდა 404-ს; ეს არც ღია ლიცენზიაა და არც გამოყენების პირობების შემცვლელი. Finland Studyinfo-ის შემოწმებულ `robots.txt`-ში მითითებულია 30-წამიანი crawl-delay და საძიებო გვერდების შეზღუდვები; მისი შემდგომი იმპორტისთვის საჭიროა ცალკე შემოწმებული წვდომისა და ხელახალი გამოყენების პირობები.

გარე მოთხოვნების ნაგულისხმევი ლიმიტია სამი ინსტიტუციური მუშაკი, 250 მილიწამიანი გაშვების ინტერვალი და მაქსიმუმ სამი მცდელობა. ადაპტერი შეზღუდულად იმეორებს დროებით 429/502/503/504 შეცდომებს და ითვალისწინებს `Retry-After`-ს. CAPTCHA ან დაცული ინტერფეისი არ ივლება გვერდის ავლით.

## განახლების პროცესი

ყველა ბრძანება სრულდება პროექტის ძირეული საქაღალდიდან, Node.js 24-ით. PowerShell-ში გამოიყენეთ `npm.cmd`, თუ `npm.ps1` შეზღუდულია.

ოფიციალური წყაროს ჩამოტვირთვა და იმპორტის **მშრალი შემოწმება**:

```powershell
npm.cmd run programs:sync -- --source daad-international-programmes
```

უკვე შენახული ადგილობრივი სურათის გადამოწმება ქსელის ხელახალი ჩამოტვირთვის გარეშე:

```powershell
npm.cmd run programs:sync -- --source daad-international-programmes --from-cache .program-cache/daad-international-programmes.json
```

ანგარიშის შემოწმების შემდეგ ვალიდური შედეგის შენახვა:

```powershell
npm.cmd run programs:sync -- --source daad-international-programmes --from-cache .program-cache/daad-international-programmes.json --write
npm.cmd run catalog:check
npm.cmd run funding:check
npm.cmd test
npm.cmd run build
```

`--write`-ის გარეშე `programs.json` არ იცვლება. `--from-cache` მიუთითებს პროექტის შიგნით არსებულ რეალურ JSON სურათზე; ქეშის ხელახლა წაკითხვა მის შემოწმების თარიღს არ აახლებს. ნედლი ქეში შეიცავს საწყის ჩანაწერებს, ხოლო იმპორტის ანგარიში — მიღებულ, განახლებულ და დაუკავშირებელ ჩანაწერებსა და მათ მიზეზებს. ჩვეულებრივი ახალი ქსელური გაშვება ადგილობრივ ქეშს ავტომატურად არ ქმნის.

ცარიელი, დაუსრულებლად ჩამოტვირთული ან ვალიდაციას ვერ გავლილი წყარო სამუშაო კატალოგს არ უნდა ჩაანაცვლებდეს. ადაპტერის `maxPages`-ით შეზღუდული სურათი მკაფიოდ არასრულია და `sync-programs.js` მას დასრულებულ იმპორტად არ იღებს. დომენის ცალკეული გადამოწმების წარუმატებლობა დანარჩენ ნამდვილ ჩანაწერებს არ ყალბავს: შესაბამისი ჩანაწერები დაკავშირების შემოწმებას ვერ გაივლის და ანგარიშში დარჩება.

შენახვის შემდეგ ლოკალური სერვერი გადატვირთეთ. Vercel-ისთვის `npm.cmd run build` ხელახლა ქმნის საჯარო სტატიკურ `catalog.json`-ს; საჯარო საიტი ახალ სურათს მხოლოდ ახალი გამოქვეყნების შემდეგ მიიღებს. დაწესებულებების upstream განახლებისთვის ცალკე გამოიყენება `npm.cmd run catalog:sync`; ის პროგრამებსა და დაფინანსებას არ მოიგონებს.

დაფინანსების 12 სქემის კავშირები, ვადები და სტატუსები აღწერილია [დაფინანსების წყაროებში](FUNDING-SOURCES.md).
