# პაროლის აღდგენის ჩართვა

სტუდენტის, მრჩევლისა და ადმინისტრატორის საკუთარ ანგარიშზე აღდგენის გზა ერთია: შესვლა → „დაგავიწყდა პაროლი?“ → ანგარიშის ელფოსტა → ერთჯერადი ბმული → ახალი პაროლი. ადმინისტრატორის უფლება პაროლის აღდგენისას არ იცვლება. სხვისი ანგარიშის პაროლი საჯარო ფორმიდან პირდაპირ არ იცვლება.

**შესული მომხმარებლისთვის უკვე მუშაობს:** პროფილი → ანგარიშის უსაფრთხოება → მიმდინარე და ახალი პაროლი. წარმატების შემდეგ სხვა სესიები მთავრდება; მიმდინარე სესია ახლდება. ეს ელფოსტის სერვისს არ მოითხოვს.

## რა უნდა მოამზადო

1. გახსენი ტრანზაქციული ელფოსტის სერვისი, რომელსაც SMTP აქვს. დაადასტურე გამომგზავნი ელფოსტა/დომენი და შეასრულე პროვაიდერის DNS მოთხოვნები (SPF/DKIM, საჭიროების შემთხვევაში DMARC).
2. პროვაიდერის პანელიდან აიღე SMTP host, port, მომხმარებელი და პაროლი. ეს შესაძლოა ჩვეულებრივი საფოსტო ყუთის პაროლისგან განსხვავდებოდეს.
3. `Server/.env`-ში დაამატე მნიშვნელობები. შაბლონი: [Server/.env.example](../Server/.env.example).

```dotenv
ENABLE_PASSWORD_RECOVERY=true
PUBLIC_SITE_URL=https://globaleduai.vercel.app
RECOVERY_SMTP_HOST=your-provider-host
RECOVERY_SMTP_PORT=587
RECOVERY_SMTP_USER=your-smtp-user
RECOVERY_SMTP_PASS=your-private-smtp-password
RECOVERY_MAIL_FROM=your-verified-sender@example.com
RECOVERY_SIGNING_SECRET=your-random-secret-at-least-32-characters
```

ეს მაგალითია — მნიშვნელობები რეალურ მონაცემებად არ ჩათვალო. შემთხვევითი საიდუმლოს შესაქმნელად გამოიყენე პაროლების მენეჯერი ან `node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"` საკუთარ ტერმინალში. შედეგი ჩატში/Git-ში არ გამოაქვეყნო.

4. იგივე მონაცემები დაამატე Vercel-ის **Project → Settings → Environment Variables → Production** განყოფილებაში და გაუშვი ახალი deployment. გასაღებებს არ უნდა ჰქონდეს `NEXT_PUBLIC_` ან სხვა საჯარო პრეფიქსი.
5. საკუთარი სტუდენტის ანგარიშით მოითხოვე ბმული, გადაამოწმე Inbox/Spam, შეცვალე პაროლი და შედი. იგივე გაიმეორე საკუთარ ადმინის ანგარიშზე. გადაამოწმე, რომ ძველი პაროლი აღარ მუშაობს, ხოლო ადმინისტრატორის უფლება შენარჩუნებულია.

ბმული 20 წუთს მოქმედებს და ერთხელ გამოიყენება. მოთხოვნები იზღუდება IP-ისა და მიმღების მიხედვით, Vercel-ის სხვადასხვა პროცესშიც. გასაღების შეცვლა ძველ ბმულებს გააუქმებს.

სანამ SMTP არ არის გამართული, გვერდი ამას პირდაპირ წერს და წერილის გაგზავნას არ აცხადებს. საიტზე პაროლის შეცვლისთვის მომხმარებელს მოქმედი პაროლი მაინც შეუძლია გამოიყენოს.
