# GPA 0–4

სტუდენტის ფორმა იღებს GPA-ს **0–4 სკალაზე**, ათწილადების ჩათვლით. უცნობი შედეგი რჩება ცარიელი (`null`), ხოლო `0` ნამდვილი რიცხვითი მნიშვნელობაა.

| მონაცემი | სკალა |
|---|---|
| პროფილის `gpa4` | 0–4 |
| პროგრამის `requirements.gpaMin4` | ოფიციალურად გამოქვეყნებული მინიმუმი 0–4-ზე |
| ძველი API-ის `gpaPercent` | 0–100%, მხოლოდ აშკარად მითითებული ძველი ფორმატი |
| პროგრამის `requirements.gpaMinPercent` | ოფიციალურად გამოქვეყნებული პროცენტული მინიმუმი |

ეს ორი სკალა ერთმანეთში არ გადაითვლება ზოგადი ფორმულით. თუ სტუდენტს აქვს `3.5 / 4`, ხოლო უნივერსიტეტს მითითებული აქვს `70%`, შეფასება ამბობს, რომ ოფიციალური ეკვივალენტობა გადასამოწმებელია. სისტემა არც `87.5%`-ს იგონებს და არც სტუდენტს გაუმართლებლად გამორიცხავს.

ერთ პროფილში ერთდროულად ორივე აკადემიური სკალა დაუშვებელია. AI-თან ფორმიდან გაზიარება აგზავნის `gpa4`-ს; ძველი პროცენტი და არქივირებული პროფილის მონაცემი იქ არ გაიგზავნება.

შენახული ძველი ბრაუზერული პროფილის პროცენტი გადადის `legacyAcademicRecord`-ში, `scale:100` ნიშნით. ახალი GPA ველი ცარიელი რჩება და სტუდენტს ხელახლა შეყვანა ეთხოვება. ძველი რიცხვი აქტიურ GPA-ს ვერ ჩაანაცვლებს.

შესაბამისობის ქულა კვლავ **0–100**-ია. ეს GPA-ს სკალა და მიღების პირადი ალბათობა არ არის. მხოლოდ იმავე სკალის ცნობილი მოთხოვნები შედარდება; უცნობი ან შეუდარებელი მოთხოვნა მონაცემთა დაფარვას ამცირებს. `academicMarginScale` განასხვავებს 4-ქულიან სხვაობას პროცენტული პუნქტებისგან; შეუდარებელ შემთხვევაში ორივე აკადემიური სხვაობის ველი `null`-ია.
