# სასაუბრო AI მრჩეველი

GlobalEdu-ს სასაუბრო მრჩეველი იყენებს OpenAI Responses API-ს. კითხვაზე ტექსტური პასუხის გარდა მას შეუძლია დამოუკიდებლად გამოიძახოს ადგილობრივი კატალოგის **მხოლოდ წაკითხვის** ხელსაწყოები. ფორმის წესებზე დაფუძნებული შეფასება ცალკე რჩება; სასაუბრო აგენტი მის შედეგებს განმარტავს, მიღების ალბათობას კი არ იგონებს.

## ჩართვა

სერვერის გარემოში, `Server/.env` ფაილში დაამატეთ:

```dotenv
OPENAI_API_KEY=your-openai-api-key
OPENAI_MODEL=gpt-5.4-mini
```

`your-openai-api-key` არის მხოლოდ მაგალითი და აგენტს არ ააქტიურებს. ნამდვილი გასაღები დაამატეთ ლოკალურად გარემოს ფაილში; ჩატში ან ბრაუზერის კოდში მისი ჩაწერა საჭირო არ არის. შემდეგ გადატვირთეთ სერვერი. მოდელის ნაგულისხმევი მნიშვნელობაა `gpt-5.4-mini`; წვდომა, კვოტა და ბილინგი განისაზღვრება თქვენი OpenAI API პროექტით.

გასაღების არქონისას `GET /api/advisor-agent/status` აბრუნებს `enabled:false`, ხოლო საუბარი — მკაფიო `503 AI_NOT_CONFIGURED` პასუხს. იმიტირებული „AI პასუხი“ ან ოფლაინ სათადარიგო საუბარი არ გენერირდება. გასაღების არსებობისას `enabled:true` მხოლოდ კონფიგურაციის არსებობას ნიშნავს — არა ანგარიშის, ქსელის, ბალანსის ან მოდელთან წარმატებული კავშირის დადასტურებას.

## API

- `GET /api/advisor-agent/status` → `{ enabled, provider:"openai", model, reason }`.
- `POST /api/advisor-agent/chat` → `{ messages:[{role:"user"|"assistant",content:"..."}], profile?:object|null }`.
- წარმატებული პასუხი: `{ reply, sources:[{title,url,kind}], matches:[{id,name,kind,title?,countryCode?}] }`.

`matches` არის ამ ბრუნვაში ხელსაწყოთი წაკითხული ჩანაწერების ბარათები; ეს სია უნივერსიტეტების რეიტინგს ან გარანტირებულ რეკომენდაციას არ წარმოადგენს. `sources` შეიცავს მაქსიმუმ რვა უსაფრთხო HTTP(S) ბმულს მხოლოდ რეალურად წაკითხული ჩანაწერებიდან. უცნობი/დაუდასტურებელი ბმული მრჩეველის ტექსტში გადამოწმებულ წყაროდ არ გაიცემა.

ისტორია შეზღუდულია 16 შეტყობინებით და ჯამში 24,000 სიმბოლოთი. მომხმარებლის თითოეული შეტყობინება მაქსიმუმ 2,000 სიმბოლოა; ისტორიული მრჩეველის პასუხი — 8,000. ბოლო შეტყობინება მომხმარებელს ეკუთვნის. სისტემური შეტყობინებები, ფუნქციის შედეგები და თვითნებური ინსტრუქციების ველები კლიენტიდან არ მიიღება.

## ხელსაწყოები და შეფასება

1. `search_universities(query,countryCode)` — უნივერსიტეტის სახელის/დომენის ძიება დირექტორიაში.
2. `find_programs(countryCode,degree,field)` — კონკრეტული, ოფიციალური წყაროს მქონე პროგრამების მოძიება.
3. `get_program_details(programId)` — საფასური, ვალუტა, პერიოდი, მოთხოვნები, ვადა და წყაროები ერთი პროგრამისთვის.
4. `assess_program(programId)` — მომხმარებლის მიერ ცხადად გაზიარებული შერჩევის პროფილის მიხედვით არსებული კატალოგისა და შეფასების წესების გამოყენება.

ყველა ხელსაწყოს აქვს მკაცრი JSON სქემა და დამატებითი სერვერული ვალიდაცია. არასწორი ქვეყნის კოდი ან უცნობი სფერო ფართო, შეუზღუდავ ძიებად არ გარდაიქმნება. კატალოგის სახელის/ვებსაიტის დირექტორიაში ყოფნა აკრედიტაციას, მიღების პირობებს ან კონკრეტული პროგრამის არსებობას არ ადასტურებს.

უცნობი თანხა რჩება `null`; ვალუტა ან პროგრამის სრული საფასური ავტომატურად არ გადაითვლება. უფასო სწავლა ცხოვრების ხარჯების დაფინანსებას არ ნიშნავს. შეფასებისას რჩება შეუსაბამობის, ინფორმაციის ნაკლებობისა და წყაროს სიახლის განმარტებები. პირადი მიღების ალბათობა ყოველთვის უცნობია; ოფიციალური ისტორიული კოჰორტის მაჩვენებელი მას არ უდრის.

## პროფილი და კონფიდენციალურობა

პროფილის გაზიარება ნაგულისხმევად გამორთულია. მხოლოდ ცხადი არჩევანისას იგზავნება შერჩევის კრიტერიუმების შეზღუდული ნაკრები: ქვეყნები, მიმართულებები, საფეხური, ენა, ბიუჯეტი, მოსწრება, გამოცდის ქულები, გამოცდილება, მოქალაქეობის კოდი და პრიორიტეტები. ანგარიშის სახელი, ელფოსტა, ტელეფონი, პაროლი, ID და სხვა პროფილის ველები სერვერის სიიდან გამოირიცხება.

თუ ცნობილი შერჩევის კრიტერიუმი არასწორია — მაგალითად დაუზუსტებელი TOEFL სკალა, უცნობი სერტიფიკატის რიცხვითი ქულა, ვალუტის გარეშე მითითებული ბიუჯეტი ან არასწორი ქვეყანა — მოთხოვნა მკაფიო `400` შეცდომით ბრუნდება; კრიტერიუმი არ იკარგება და პირობები ჩუმად არ მსუბუქდება.

მრჩეველი არ კითხულობს ანგარიშების ბაზას, არ აგზავნის წერილებს/აპლიკაციებს, არაფერს ჯავშნის და არ ცვლის ფავორიტებს. ჩატის ტექსტი, ბოლო შეტყობინებები და ხელსაწყოს დროებითი შედეგები ამ სერვერზე საუბრის მოთხოვნის მეხსიერებაშია; არც დისკზე და არც ანგარიშის ბაზაში არ ინახება.

OpenAI მოთხოვნაში გამოყენებულია `store:false`; დიალოგის ხელით გადაცემა და დაშიფრული reasoning ელემენტების დაბრუნება ინარჩუნებს ამ ერთი ბრუნვის ხელსაწყოების კონტექსტს. **ეს არ ნიშნავს Zero Data Retention-ს** და არ ცვლის OpenAI API პროექტის მოქმედ მონაცემთა დამუშავების პირობებს. გაგზავნილი ტექსტი და მომხმარებლის ნებით გაზიარებული კრიტერიუმები მაინც იგზავნება OpenAI-სთან.

## ლიმიტები და შეცდომები

ერთ IP-ზე მოქმედებს 20 ცდა 15 წუთში; ერთდროულად მუშავდება მაქსიმუმ ოთხი ბრუნვა. ერთი ბრუნვა მოიცავს მაქსიმუმ ოთხ მოდელის მოთხოვნას და ექვს კატალოგის ხელსაწყოს გამოძახებას. მთელი დამუშავების ვადა მაქსიმუმ 45 წამია. ავტომატური განმეორებითი ფასიანი ცდები არ სრულდება; გაჩერებული კლიენტის მოთხოვნა provider-ის მოთხოვნასაც აუქმებს.

შეცდომები არის მოკლე, მომხმარებლისთვის გასაგები პასუხები: `400` არასწორი მონაცემი, `403` დაუშვებელი origin, `429` ადგილობრივი/პროვაიდერის დროებითი ლიმიტი, `503` კონფიგურაციის/კავშირის/ბილინგის მიუწვდომლობა, `504` დროის ამოწურვა, `502` არასრული/არასწორი provider პასუხი. გასაღები, provider-ის შეცდომის სრული ტექსტი ან საიდუმლო კონფიგურაცია ბრაუზერსა და ჟურნალებში არ იგზავნება.

### ადმინისტრატორისთვის: კრედიტები და ხარჯვის ლიმიტები

პროვაიდერის HTTP `429` ყოველთვის დროებით სიხშირის ლიმიტს არ ნიშნავს. ცნობილი ბილინგის კოდები `credit_balance_exhausted`, `organization_spend_limit_exceeded`, `project_spend_limit_exceeded`, `organization_usage_limit_exceeded` და `insufficient_quota` (ან იგივე error type) აბრუნებს **`503 AI_QUOTA_UNAVAILABLE`**-ს. მომხმარებელი ხედავს მხოლოდ მომსახურების მიუწვდომლობასა და ადმინისტრატორთან დაკავშირების მითითებას; `Retry-After` არ იგზავნება და ავტომატური განმეორებითი ფასიანი ცდა არ სრულდება.

ადმინისტრატორმა უნდა გადაამოწმოს შესაბამისი OpenAI API პროექტის კრედიტები, ბილინგი და ორგანიზაციის/პროექტის ხარჯვის ლიმიტები. კრედიტების ან უფლებების შეცვლის შემდეგ შესაძლებელია ახალი ხელით საცდელი კითხვა. გასაღების შეცვლა მარტო ამ ფინანსურ შეზღუდვას არ ადასტურებს ან აგვარებს. უცნობი/ჩვეულებრივი დროებითი `429` რჩება `AI_PROVIDER_LIMIT`-ად და აქვს შეზღუდული `Retry-After` მინიშნება. [ოფიციალური შეცდომების განმარტება](https://developers.openai.com/api/docs/guides/error-codes).

## შემოწმება

აგენტის ტესტები იყენებს ჩასანაცვლებელ `fetchImpl`-ს და კონტროლირებად პასუხებს; ისინი რეალურ OpenAI მოთხოვნებს არ ასრულებს. რეალური მოდელის მუშაობა დასტურდება მხოლოდ საკუთარი API გასაღების დაყენების შემდეგ localhost-იდან წარმატებული კითხვით. გასაღების გარეშე რეალური პასუხის წარმატება არ ივარაუდება.

ოფიციალური დოკუმენტაცია: [Responses function calling](https://developers.openai.com/api/docs/guides/function-calling), [conversation state](https://developers.openai.com/api/docs/guides/conversation-state), [GPT-5.4 Mini](https://developers.openai.com/api/docs/models/gpt-5.4-mini).
